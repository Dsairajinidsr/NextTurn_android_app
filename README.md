# NextTurn – Smart Virtual Queue Management System

## About the Project
NextTurn is an Android application designed to simplify queue management by allowing patients to manage their visits digitally. It helps reduce waiting time and makes queue handling easier for patients, staff, and managers.

## Features
- Patient registration and login
- Staff registration and login
- Manager login
- Digital queue and token management
- QR code generation and scanning
- Patient notifications
- Patient profile management
- Manager reports and activity tracking

## Technology Stack
- **Platform:** Android
- **Programming Language:** Java
- **UI:** XML
- **Backend:** Firebase
- **Database:** Cloud Firestore
- **Authentication:** Firebase Authentication
- **Notifications:** Firebase Cloud Messaging

## User Roles
- **Patient:** View queue information, tokens, notifications, and profile.
- **Staff:** Manage queues and patient information.
- **Manager:** Monitor activities and view reports.

## Installation
1. Clone this repository.
2. Open the project in Android Studio.
3. Configure your Firebase project and add the required `google-services.json` file.
4. Sync the Gradle files.
5. Run the application on an Android emulator or device.

## Project Purpose
The goal of NextTurn is to make queue management more convenient, organized, and efficient through a digital solution.
